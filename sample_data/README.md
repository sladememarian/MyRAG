# Sample data

Three short Persian documents, generated by `generate_samples.py`, plus
questions that exercise grounding, tables and "not in the documents".

| File | Content |
|---|---|
| `01-jangal-iran.docx` | Iranian forests (Hyrcanian, Zagros), rainfall, animals + a table |
| `02-tehran.docx` | Tehran, population, Milad Tower, metro, airport + a table |
| `03-company-rules.docx` | Working hours, leave, remote work, sick leave + a table |

Generate/refresh the `.docx` files:

```bash
docker compose run --rm web python sample_data/generate_samples.py
```

## Test questions and expected answers

| Question | Expected behaviour |
|---|---|
| جنگل هیرکانی کجاست؟ | North of Iran, in Golestan, Mazandaran and Gilan. |
| جنگل‌های زاگرس بیشتر از چه درختی تشکیل شده‌اند؟ | Oak (بلوط). |
| میزان بارندگی سالانه در جنگل‌های شمال ایران چقدر است؟ | Between 800 and 2000 mm. |
| بلندترین برج ایران چه نام دارد و چه ارتفاعی دارد؟ | Milad Tower, 435 metres. |
| متروی تهران چند خط دارد؟ | 7 lines. |
| ساعت کاری شرکت در روز پنجشنبه چگونه است؟ | 9 to 13. |
| هر کارمند چند روز در سال مرخصی استحقاقی دارد؟ | 26 days. |
| حداکثر چند روز در هفته می‌توان دورکاری کرد؟ | 2 days, with manager approval. |
| پایتخت آلمان کجاست؟ | "Not in the documents" — must **not** answer Berlin. |
| قیمت بیت‌کوین امروز چقدر است؟ | "Not in the documents" — no invented numbers. |

## Suggested demo script

1. Upload all three files in admin (or via `POST /api/documents/`).
2. Ask two answerable questions (one from a paragraph, one from a table).
3. Ask one unanswerable question to show the grounding rule.
4. Open `/api/history/` to show the three stored rows, answers and sources.

> Answers are generated by a free model and can be phrased differently each
> time, but the facts must match the table above and the sources must point to
> the right document.
